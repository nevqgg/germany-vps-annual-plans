## 三网回程具体走的是什么路由

回程三网走 CN2 GIA（电信 AS4809，路由中出现 59.43 节点），移动回程走 CMIN2；去程按运营商分开走。CN2 GIA 与普通电信 163 骨干（AS4134）的差别在于晚高峰拥塞程度，这也是德国机房能把 ping 压在 180ms 上下的主要原因。

去程的记载存在分歧。电信去程走 CN2 GIA，有一份资料提到先落地伦敦节点再转法兰克福；移动去程走 CMI 直连法兰克福，这两项说法一致。联通去程有两种版本，一种写 CN2 GIA，一种写 AS4837 直连法兰克福，两份资料都是第三方页面，没有官方背书，无法判断哪份更新。联通用户如果在意这一段，别信任何二手描述，自己跑一次路由最直接。

去程和回程要分开看，因为它们走的是两条不同的路。你去连服务器、上传文件走的是去程，服务器把内容送回来走的是回程，看视频、拉数据、开网页主要吃回程。国内到欧洲的物理往返时延下限就在几十毫秒量级，剩下的上百毫秒全花在路由跳数和拥塞上，这也是为什么同样标着“德国法兰克福”，实际体验能差出一倍。

官方提供测试 IP **185.217.109.94** 和法兰克福机房的 Looking Glass 测试页，下单前 ping 一下、跑一次 traceroute，看自己所在运营商到法兰克福的实际延迟和回程是否落在 59.43 段，比看任何测评都准。移动用户重点看回程是否走 CMIN2。

## 常见问题

**德国机房延迟为什么能压到 180ms 上下？**
中德之间的物理距离决定了往返延迟下限在几十毫秒量级，剩下的部分取决于路由。走 CN2 GIA 时跳数少、晚高峰不挤 163 骨干，第三方测评给出的国内平均 ping 是 177ms 左右，电信联通在 170ms 出头，移动略高。这是测评数据，你所在地区的实际值要用测试 IP 自己测。

**季付和年付只是价格不同吗？**
带宽也不同。同一配置季付 500Mbps，年付 1000Mbps，这是选年付时容易被忽略的一半理由。

**能退款吗？**
不能。条款写明不允许退款，也不接受“非原生 IP”为由的申请。先用短周期套餐试水是唯一稳妥的做法。

**流量双向计算是什么意思？**
上传加下载一起算进月配额。1200GB 的套餐，上传 600GB 加下载 600GB 就用满了。

**IP 是原生德国 IP 吗？**
不保证。官方明确说明不保证原生 IP，有特定归属地需求的场景要提前评估。
